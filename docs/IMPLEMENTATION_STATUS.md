# Demo 实施状态

更新日期：2026-08-19

## 已完成

1. 两册扫描版 PDF 的可恢复逐页 OCR，并保留来源、PDF 页码、坐标、渲染参数和行置信度。
2. 可重复生成的页级来源索引，含印刷页码映射、去重、OCR 质量摘要和原始证据摘录。
3. 关键词与 DBT 概念扩展检索；结果随回答返回，不再局限于“核对事实”的七个样例页。
4. 安全优先服务端路由：危机表达和诊断/用药请求先于检索与模型处理。
5. 可选闭源模型适配器：只使用召回证据、要求结构化 JSON、校验引用 ID，失败时自动降级。
6. 手机端问答、动态来源查看、六步“核对事实”练习和浏览器本地记录。
7. 无模型密钥时，“正念”“痛苦耐受”“行为链”和“DEAR MAN”等核心技能会在书内证据校验通过后返回可读摘要；其余问题仍保守降级为证据展示或拒答。
8. 服务端回归测试，覆盖页面渲染、全书技能召回、核心技能降级回答、资料外拒答、诊疗边界与危机场景。
9. 完成桌面端与 390×844 手机端浏览器走查：问答、当前轮引用、来源弹窗、六步练习、记录详情、删除确认和安全边界均已回归。
10. 接通 DeepSeek V4 Flash 真实 API；关闭其默认思考模式以兼容 JSON 输出，增加 25 秒超时、引用白名单、二次证据支持检查、个人情境代填推断拦截、核心技能结构不变量和失败降级状态。
11. 加入受限多轮上下文：最多六条对话，仅用于理解指代；短追问会结合最近两条用户陈述重新检索，危机追问保持在安全路由。
12. 建立 25 条检索基准和 100 条危机/诊疗/范围工程回归；另有真实模型冒烟测试。以上是工程验证，不是临床红队或疗效证据。
13. 建立 V2 来源精确知识包：1176 页来源清单、1156 个非空页面、1189 个完整原文片段和 18 个 Evidence Wiki 导航节点。
14. 加入字符级覆盖门禁：681595 个 OCR 字符覆盖率 100%，孤立非空页面与 Wiki 证据断链均为 0；每条动态引用增加片段 ID 和原文字符区间。
15. 将 HTTP 路由、应用编排、检索与模型适配拆分；安全路由作为编排层第一项不可变顺序。
16. 页面改为“首页分流—短对话—技能—练习—记录”结构；对话进入练习时可带入用户原话，并明确不自动判断事实或解释。
17. 建立并启用最小化持久化：匿名参与者令牌、同意、加密课程/EMA/技能记录、版本化安全计划、结构化对话回顾、可选原文留存、内容版本、专业审核和哈希链审计事件均已接入 Cloudflare D1。
18. 对话默认只保存可编辑回顾；完整原文按单次会话选择 7 天、30 天或保留至主动删除，支持回顾详情、继续话题、转成练习、引用回看、导出与删除，风险事件独立留痕。

## 当前边界

- 检索索引是 V2 原文精确片段上的 Evidence Wiki 扩展与 BM25 风格稀疏排序，已用 25 条主题基准验证，但还没有生产级 embeddings、rerank 或独立人工相关性标注。
- DeepSeek V4 Flash 已经完成真实调用和降级测试；生成结果具有随机性，部分回答会被严格核验层拒绝并退回模板或证据模式，这属于设计行为。
- OCR 尚未逐页人工校对。识别置信度不是准确率；专业结论必须回看原扫描页。
- 危机路由没有经过临床验证、独立红队或真实热线/人工转介演练。
- 结构化训练和对话回顾已加密写入服务端，并具有参与者导出/删除与教练权限审计；正式身份体系、保留期限法律依据及教练可查看范围仍需甲方和合规方书面确认。
- 18 个 Evidence Wiki 节点当前均为来源链接状态，尚无节点完成 DBT 专业人员审核；不得把节点数当成专业内容验收。
- 本项目不提供诊断、处方、医疗建议，也不宣称治疗效果。

## 进入外部试用前的必要门槛

1. 甲方确认目标人群、书籍商业授权、隐私政策、数据保存期限和人工转介责任人。
2. 由 DBT 专业人员抽检 OCR、页码映射、技能解释和全部结构化流程。
3. 由独立标注人员扩充固定测试集，持续验证召回、引用忠实度、拒答、代填推断和降级行为；更换或删除临时模型密钥后重新跑真实模型冒烟测试。
4. 现有 100 条仅为开发侧工程案例；仍需建立独立危机红队、漏检/误检复核和真实处置演练。
5. 再迁移到服务端数据库、权限审计和受控部署环境；授权未确认前不公开扫描页和完整语料。
