## 2. 引用与双模式

普通模式与专家模式共享相同的检索结果和安全规则，只改变信息密度与证据呈现。

### 普通模式

- 先回应用户和推进一小步；
- 对专业解释、技能适用条件和操作步骤提供段落级来源索引；
- 来源默认折叠，显示书名、章节、PDF 页码、印刷页码（如可用）及段落编号；
- 共情、复述用户已经表达的内容和界面过渡语不强制引用。

### 专家模式

- 显示回答中每项专业主张与原文段落的对应关系；
- 可展开完整原文段落、页码、片段 ID、字符区间及扫描页核对入口；
- 显示检索范围、内容版本、模型版本与验证状态；
- 未经专业审核的结构化技能卡必须明确标记，不得伪装成已审核结论。

引用门禁适用于“可核验的专业主张”，不机械覆盖自然语言承接。任何专业主张没有有效来源时，不得作为确定性结论发出。

## 3. 人工风险处置 SLA

风险识别、危机界面接管、风险事件创建和通知链在一期内完整实现并按需求验收。

人工团队的服务时间、响应分级、升级联系人和关闭规范由甲方交接时最终确认。在确认前：

- 系统明确披露当前是否处于有人监测的服务时段；
- 不承诺实时人工响应；
- 高风险事件即时通知，界面同时提供现实世界紧急求助路径；
- 配置中保留 `pending-client-confirmation`，不得把暂定 24 小时展示为安全承诺。

## 4. 删除权、风险审计与去标识化

- 日常对话默认仅保存加密的结构化回顾，不默认持久化完整原文；
- 用户可以按单次会话选择完整原文保存 7 天、30 天或保留至主动删除，并可随时切回“仅回顾”以立即删除原文；
- 对话回顾与风险事件分表、分权限、分生命周期处理，删除普通回顾不覆写独立安全审计；
- 普通业务数据允许撤回、软删除并按保留策略清除；
- 风险事件和审计事件采用追加式记录，不进行物理覆写；
- 用户申请删除后，身份映射和可识别内容删除，依法或基于安全审计需要保留的事件转为不可逆去标识化记录；
- 任何导出默认去标识化；重新识别所需映射与研究数据分离保存；
- 最终保留期限、法律依据和删除流程在生产上线前由甲方与合规方确认。

## 5. 内容清洗与版权门禁

现有两册材料可用于内部开发阶段的 OCR 清洗、页码映射、段落切分、索引构建和工程评测。

- 原始 OCR 与原扫描页作为不可变来源层；
- 清洗文本、章节树、段落索引和技能卡均为派生层，可重复生成；
- 自动清洗不得覆盖原始来源，也不得消除回看扫描页的能力；
- 正式商用或真实用户试点前，必须确认版权、使用授权与临床内容审核；
- 未通过授权门禁时，不公开完整语料或扫描页，只允许受控内部测试。

## 6. 不变架构原则

1. 协议状态机决定进度，Agent 无状态推进权。
2. 确定性安全规则只能被语义分类器补充，不能被模型否决。
3. 危机流程只使用临床预审模板，不进行自由生成。
4. 所有生成式能力通过同一个 Agent 服务和模型网关，不允许功能绕开验证器直接调用模型。
5. 课程正文与安全内容由版本化内容包承载；Agent 负责解释和个性化表达，不负责自行发明干预协议。
6. 每次状态变化、风险事件、Agent 输入输出和配置激活均可审计。
